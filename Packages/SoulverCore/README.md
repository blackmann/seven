# SoulverCore 3.5.1

This package downloads the unmodified, official SoulverCore binary. Its release URL and SHA-256 checksum are pinned to the upstream 3.5.1 package manifest. Using a local binary-package manifest avoids downloading historical binaries from the upstream Git repository.

- Upstream: https://github.com/soulverteam/SoulverCore
- Manifest: https://github.com/soulverteam/SoulverCore/blob/3.5.1/Package.swift
- License: https://github.com/soulverteam/SoulverCore/blob/3.5.1/LICENSE.md

SoulverCore is closed source. Personal/private projects are permitted. Contact contact@soulver.app about a license before public or commercial distribution; the publisher offers several options, including a free license with attribution.

To update, change the release URL and checksum together using the upstream manifest, then rerun Seven's calculator tests.
